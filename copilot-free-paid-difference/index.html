Copilotの無料版と有料版の違いをひとことで言うと、「Webの情報とアップロードしたファイルだけで答えるか」と「Word・Excel・Outlookのデータや社内のファイルまで扱えるか」の差です。もう1つの差が回数で、無料版は混んでいると制限がかかり、有料版は優先して使え、使える量も増えます。ただ、「Copilot」という名前のサービスは個人向けのMicrosoft Copilot・仕事用のMicrosoft 365 Copilot・プログラマー向けのGitHub Copilotの3つに分かれていて、無料と有料の境目もそれぞれ違います。どれを使っているのかを先に決めると、迷う時間が減ります。

この記事の要点

  • Copilot Proは販売終了、個人の有料版は今M365 Premium(月3,200円)
  • 無料の仕事用Copilot ChatはWord・Excelの社内データを横断しない
  • GitHub Copilot Freeは補完が月2,000回、有料版は補完が無制限

向いている人: Copilotを仕事で使うため、課金するか迷っている会社員・個人事業主

Microsoft Copilot(Windows・Edge)の無料版と有料版の違いは何か

個人向けのMicrosoft Copilotは無料で使えますが、混雑時は制限があり、画像生成や音声などの回数も少なめです。有料版は今はMicrosoft 365 Personal・Family・Premiumで、WordやExcelの中でCopilotを使え、回数の上限も上がります。

Copilot Proは販売終了。いまの有料版はMicrosoft 365 Premium

2025年10月に、Microsoftは個人向けの最上位プラン「Microsoft 365 Premium」を発表しました。Copilot Proは同時に販売終了です(Windows Blog for Japan)。公式サポートにはこう書かれています。

「Copilot Proは購入できなくなります。」(Microsoft サポート「Microsoft Copilot Pro について」)

すでに契約していた人も、同じページによれば「2026 年 8 月 1 日にキャンセルまたはサポートが終了するまで」しか使えません。今日(2026年10月26日)の時点で、Copilot Proを選ぶ道はもうないわけです。Premiumは「Microsoft 365 Family および Copilot Pro のすべての機能」に加えて、ResearcherやAnalystといった推論エージェントも使えるプランとして案内されています(Windows Blog for Japan)。

仕事の場面で何が変わるか

たとえば個人事業主が、見積書をExcelで作っているとします。無料版の場合は、ブラウザでCopilotを開いて表をコピーして貼り、質問して、答えをまたExcelに戻す流れです。Personal以上なら、Excelを開いたままCopilotに「この表で売上が前の月より下がった行に色をつけて」と頼めます。コピーして貼る手間がなくなる。違いはここです。

注意点

AIの機能は共有できません。Familyは最大6人で使えるプランですが、公式の比較ページには「AI機能はサブスクリプション所有者のみが使用でき、共有できません」とあります(Microsoft 365 の個人向けプラン比較)。家族全員がCopilot付きのWordを使えると思って契約すると、あてが外れます。

もう1つは値上げの件です。Personal・FamilyはCopilotが入ったときに値上がりしました。年額は、Personalが14,900円から21,300円になっています(Impress Watch・2025年1月)。AIがいらない既存の契約者向けには、前の価格のままの「Classic」プランが用意されました。今も選べるかは、Microsoftアカウントのサブスクリプション画面で確かめてください。

Microsoft 365 Copilotの無料版と有料版の違いは何か

仕事用の無料版「Copilot Chat」は、Webの情報と自分で渡したファイルをもとに答えるチャットです。有料のMicrosoft 365 Copilotは、メール・会議・チャット・社内ファイルを横断して調べ、優先アクセスも付きます。

Copilot Chatは、対象のMicrosoft 365プランを使っている人に「追加費用なしで含まれる Web 典拠型 AI アシスタント」と案内されています(Microsoft Copilot 法人向け価格)。会社がMicrosoft 365を契約していれば、多くの人は今日から無料で使えます。

公式の比較表を数えると、無料で全部使えるのは9項目中4つ

Microsoft Learnの「Copilot Chat と Microsoft Copilot を比較する」の表には9項目が載っています。そのうちCopilot Chatが条件なしで「はい」なのは4項目でした。残りは、条件つきの「はい」が1、「制限あり」が2、「なし」が2です(Microsoft Copilot Chatの概要・2026-10-26に数えた)。中身を整理すると次のとおりです。

「無料でもWordにCopilotが出る」の正体

Word・Excel・PowerPoint・OneNoteに出てくる表示は3種類あります。Microsoft Learnによると、こう分かれます(Microsoft Copilot Chatの概要)。

  • 「Microsoft 365 Copilot (Premium)」か「(Pro)」:有料のアドオンライセンスがあり、アプリの中で全部の機能を優先して使える
  • 「Microsoft 365 Copilot (基本)」:ライセンスはないが、アプリの中のCopilotに標準の優先度でつながる
  • 「Copilot Chat (基本)」:ライセンスがなく、アプリの中のCopilotチャットは使えない

自分がどれに当たるかは、アプリに出るラベルで分かります。同僚のWordではCopilotが動くのに自分のでは動かない。そんなときは、ライセンスか会社の設定(テナント構成)の違いを疑いましょう。

具体例:同じ質問でも答えの材料が違う

たとえば「先週のプロジェクトAlpineのメールを要約して」と頼む場面です。これはMicrosoft Learnが例に挙げている問いです。

  • Copilot Chat(無料)をOutlookで使う:受信トレイ・予定表・会議など、限られた範囲で答えます。Outlookの外のWeb版Copilot Chatで聞いても、メールの中身は自動では見に行きません。
  • 有料ライセンス:メール・Teamsの会議・チャット・SharePointの資料をまとめて読み、1つの答えにまとめます。

つまずきやすい所と直し方

「Copilot Chatに社内の資料を聞いても『見つからない』と言われる」というのは、よくあるつまずきです。無料版はWebが中心なので、社内ファイルを自分で探しには行きません。直し方は2つあります。ファイルをアップロードするか、本文をコピーして貼るか。それでも足りないほど何度も同じ場面がある人は、有料ライセンスを検討する目安になります。

無料版の回数にも注意が要ります。Copilot Chatのファイルアップロード・画像生成・GPT-5などのモデルは「標準アクセス」です。サービスが混むと品質や速さが下がることがあると書かれています(Microsoft Copilot Chatの概要)。

前提のライセンスが別に要る

Copilot Businessもエンタープライズ版も、基本はMicrosoft 365の「アドオン(追加)」です。対象のプランは、Copilot BusinessだとMicrosoft 365 Business Premium・Business Standard・Business Basic・Apps for business・Teams Essentialsの5つ(Microsoft Copilot のライセンス オプション)。さらに同じページには、Copilot Businessは「テナントごとに最大 300 人のライセンス ユーザーをサポート」すると書かれています。

計算の例

たとえば社員10人の会社が、すでにBusiness Standardを使っていて、Copilot Businessを全員に足すとします。割引価格なら¥2,698×10人×12か月=年¥323,760(税抜)。通常価格なら¥3,148×10人×12か月=年¥377,760(税抜)です。全員ではなく、資料作りの多い3人だけに付けるやり方もあります。ライセンスは人ごとに割り当てるので、これができます。

GitHub Copilotの無料版と有料版の違いは何か

GitHub Copilot Freeはコード補完が月2,000回まで、チャットやエージェントは少ない量のAIクレジットの範囲で使えます。有料のPro(月10ドル)からは、補完が無制限で、高性能なモデルも選べるようになります。

2026年6月1日から「AIクレジット」に変わった

GitHubは2026年6月1日に、すべてのCopilotプランを使った量で払う方式に切り替えました。それまでの「プレミアムリクエスト」は「GitHub AI Credits」に置き換わっています(GitHub Changelog・2026-06-01)。日本語の発表によると、補完は数に入りません。コード補完とNext Edit Suggestionsは全部のプランに含まれ、AIクレジットを消費しないと書かれています(GitHubブログ日本語版)。

Freeを使えない人・Proを無料で使える人

Freeは「組織やエンタープライズからCopilotを使えない個人の開発者」向けです(Plans for GitHub Copilot)。会社のGitHubでBusinessを割り当てられている人は、Freeに切り替えられません。一方で、認証された教師や人気のオープンソースのメンテナーは、Proを無料で使える場合があります。

つまずきやすい所と直し方

「月の途中で急にチャットが止まった」という場合は、AIクレジットを使い切った可能性があります。GitHubの日本語の発表では、クレジットと超過予算を使い切っても、補完とNext Edit Suggestionsは使い続けられるとしています。チャットなどほかの機能は止まります。前の仕組みでは、使い切っても軽いモデルに切り替えて続けられましたが、今は違います。直し方は3つ。

  1. 翌月を待つ。上限は毎月1日の00:00:00 UTC(日本時間で午前9時)に戻ります(Usage-based billing for individuals)
  2. 有料の個人プランなら、追加分の予算を決めて使い続ける
  3. 上のプランに切り替える

使い残したクレジットは翌月に持ち越せないので、ためておく意味はありません。AIでプログラムを書くなら、Claude Codeの無料の範囲と比べておくと選びやすくなります(Claude Code使い方|無料の範囲と料金表・導入7手順)。

Copilot無料版の利用回数制限はどのくらいか

Microsoftは個人向けCopilotの無料版について、1日何回までという決まった数を公開していません。公開されている数字ではっきりしているのは、GitHub Copilot Freeのコード補完の「月2,000回」だけです。

個人向けCopilotのFAQには、次の一文があります。

"Yes. Microsoft offers a limited free version of Copilot subject to available capacity and limits."(Copilot Pricing Plans for Individuals)

訳すと「はい。Microsoftは、空いている処理能力と上限の範囲で使える、制限つきの無料版Copilotを提供しています」。つまり無料版の回数は、混み具合で変わります。ネットで見かける「1日◯回」は、公式の数字ではありません。

Microsoftのサポートページでは、上限を数字ではなく段階で示しています。Personal・Familyは「Standard」、Premiumはそれより上、Proは「最も高い使用率」です。ページには「制限と AI クレジットの割り当ては、Microsoft 365 プランによって異なります」とあります(個人向けの Microsoft 365 サブスクリプション全体での AI の使用方法)。英語版には、上限は機能・入り口・システムの状態で変わることがあり、新しいモデルが出るたびに変わることもある、という注意書きもありました。

有料版に課金する価値があるのはどんな人か

Word・Excel・Outlookの中で毎日のようにAIに頼みたい人には、有料版の価値があります。逆に、ブラウザで質問して答えを読むだけなら、無料版のままで足ります。

判断の基準を1つ挙げるなら「アプリの中で使う回数」です。Personalにはすでに1TBのOneDriveとOfficeアプリが入っています。Officeの代わりに払うつもりなら、Copilotの分の上乗せは月640円です(Impress Watch)。いっぽう、Officeを使わない人にとっての3,200円は、ほぼAIだけの値段になります。その場合、ChatGPTやClaudeの有料プランと同じ土俵で比べることになります。料金を並べて見るならChatGPT有料プランの違いとClaude Pro料金|日本円の実額が参考になります。

デメリットも書いておきます。Premiumでも上限はなくなりません。言い方が「広範な使用」であって、「無制限」ではないのです。もう1つ、会社の機密情報を個人の契約のCopilotで扱うかどうかは、勤め先のルールしだいです。会社のアカウントで使うCopilot Chatにはエンタープライズ データ保護が付きます。個人向けのプランは、その会社の管理の外にあります。

法人向け(Copilot Business・Microsoft 365 Copilot)

向いているのは、Teams会議の要約・メールの返信の下書き・社内資料の検索を、毎日何回もしている人です。たとえば管理職が「先週の会議と関係するメールをまとめて、部長への報告の下書きを作って」と頼む場面。メール・会議・チャットをまたいで材料を集められるのは有料ライセンスだけでした(前の比較表の「Graph API・Work IQ」の行)。

向いていないのは、社内の資料がSharePointやOneDriveに入っていない会社です。紙やほかのストレージが中心だと、Copilotが読める材料がありません。また、ファイルのアクセス権が整っていない会社も要注意です。Copilotは本人がアクセスできる範囲だけを読みますが(Microsoft Copilot Chatの概要)、もともと見えすぎる設定になっていれば、見えすぎる答えが返ってきます。導入の前に共有設定を見直しておきましょう。

Microsoft 365 Copilotを個人・個人事業主で契約する方法と手順

個人ならMicrosoft 365 PersonalかPremiumを、Microsoftアカウントで申し込みます。社員を雇っている個人事業主や小さな会社なら、Microsoft 365 Business(BasicかStandard)にCopilot Businessを足します。

どちらにするかの目安は「会社としての管理が要るか」です。自分1人で、仕事のファイルも自分のOneDriveに入れているならPersonalかPremium。スタッフにアカウントを配りたい、Teamsで取引先と会議をするなら、Businessの系統が合います。

個人向け(Personal・Premium)の手順

  1. Microsoft 365 の個人向けプラン比較を開き、PersonalかPremiumを選んで「年払い」か「月払い」を決める
  2. 購入ボタンを押し、個人のMicrosoftアカウント(@outlook.jp など)でサインインする
  3. 支払い方法を登録して購入を確定する
  4. WordかExcelを開き、右上のアカウントが手順2と同じアカウントかを確かめる
  5. リボンの「Copilot」ボタンを押して、最初の指示を入れる

つまずきやすいのは手順4です。Copilotボタンが出ないときは、会社のアカウントでOfficeにサインインしていることが多いです。アカウントを個人のものに切り替えて、アプリを開き直してください。それでも出ない場合は、アプリの更新を確かめます。Copilot Proの契約が残っていた人は、2026年8月1日で使えなくなっています。Premiumに入り直す必要があります(Microsoft サポート)。

法人向け(Copilot Business)の手順

  1. Microsoft 365 Business Basic・Standard・Premiumのどれかを契約していることを確かめる(前提のライセンス)
  2. 管理者のアカウントでMicrosoft 365 管理センターにサインインする
  3. 左のメニューの「課金」→「サービスを購入」で「Copilot」を探し、Microsoft 365 Copilot Businessを選んで、使う人数分を年間契約で買う
  4. 「ユーザー」→「アクティブなユーザー」で使う人を選び、ライセンスを割り当てる(ユーザーにライセンスを割り当てる)
  5. 割り当てた人がWordやTeamsをいったん閉じて開き直し、Copilotが出るか確かめる

うまく動かないときは、Microsoftが用意している「Microsoft Copilot サービス プラン診断ツール」で、そのアカウントが要件を満たしているかを確かめられます(Microsoft Copilot のライセンス オプション)。割り当ててから反映されるまで、少し時間がかかることもあります。

年間契約には注意が必要です。公式の価格ページによれば年間サブスクリプションは自動で更新されるので、試してから決めたい人は、まず少ない人数で始めましょう。

よくある質問

Microsoft Copilotの無料版と有料版の違いは?

無料版はMicrosoftアカウントで使えるチャットで、混み具合と上限による制限があります。有料版(Personal・Family・Premium)はWord・Excel・PowerPoint・Outlook・OneNoteの中でCopilotを使え、画像生成や音声の回数も無料版より多くなります。Copilot Proは販売が終わり、今の個人向け最上位はMicrosoft 365 Premium(月3,200円・2026年10月時点)です。

M365 Copilotの無料版と有料版の違いは?

無料のCopilot Chatは、Webの情報とアップロードしたファイルで答え、Outlookの中ならメールや予定表も踏まえます。有料ライセンスは、メール・会議・チャット・社内文書をまたいで推論し、優先アクセスと高度なエージェントも付きます。料金は300人までのCopilot Businessが1ユーザー月¥2,698相当(割引中・年払い・税抜)です。

GitHub Copilotの無料版と有料版の違いは?

Freeはコード補完が月2,000回まで、チャットとエージェントは少量のAIクレジットの範囲で、モデルは自動選択だけです。Pro(月10ドル)からは補完が無制限になり、毎月1,500のAIクレジットで上位のモデルも選べます。2026年6月1日に、プレミアムリクエストからAIクレジットの方式に変わりました。

Copilot Proを契約していた人はどうなりましたか?

公式サポートによると、既存の契約は2026年8月1日に終わり、自動では更新されません。Officeアプリの中でCopilotを使い続けたい人は、Microsoft 365 Premiumなどを新しく申し込む必要があります。

会社のパソコンで個人の無料Copilotを使ってもいいですか?

決めるのは勤め先のルールです。会社のアカウントでサインインして使うCopilot Chatには、エンタープライズ データ保護が付きます。業務の文章を扱うなら、まずこちらを選ぶのが安全です。

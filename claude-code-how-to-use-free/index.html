Claude Codeとは何か、通常のClaude(チャットAI)と何が違うのか

Claude Codeは、パソコンの中のファイルを読み、書き換え、コマンドまで実行するAIエージェントです。答えを返すだけのチャットとは別の道具になります。

公式の説明は短めです。

「Claude Code is an agentic coding tool that reads your codebase, edits files, runs commands, and integrates with your development tools.」(Claude Code Docs: Overview)

訳: Claude Codeは、コード全体を読み、ファイルを書き換え、コマンドを実行し、開発ツールとつながる、自分で動くタイプのコーディングツールです。

たとえば「この売上CSVを集計するPythonスクリプトを作り、実行し、エラーが出たら直して」と頼むとします。チャットのClaudeはコードを示すところまでで、コピーして実行するのは自分です。Claude Codeはファイルを作るところから実行・修正まで、そのフォルダの中で続けて進めます。

プログラマーでなくても使えるかが気になると思います。公式ドキュメントにはターミナルを使ったことがない人向けのターミナルガイドがあり、入口は用意されています。とはいえ、ファイルやフォルダの場所が分からないと指示もしにくいです。表計算やGoogleのスクリプトで自動化から始めたい人は、ChatGPT GAS自動化、始め方の3手順のほうが入りやすいかもしれません。

claude code無料版 使い方の手順

「無料版」という製品はありません。いちばん安く始める順番は、無料講座で中身を知る→インストールして動作を確かめる→Proに1か月だけ入って試す、です。

  1. Claude Academyの「Claude Code 101」を開き、何ができるかをつかむ(無料)
  2. 次の見出しの手順でClaude Codeを入れ、claude --version で番号が出るか確かめる(無料)
  3. 料金ページでProを選び、月払いで申し込む(月20ドル・2026年10月時点)
  4. 作業用のフォルダで claude と打ち、ブラウザの画面に従ってログインする
  5. 1か月使ってみて、上限に何度もかかるならMaxに上げる。ほとんど使わなかったら解約するかConsoleの従量課金に移る

ここで大事な決まりが1つあります。ProやMaxの使用量は、チャットのClaudeとClaude Codeで共有です。公式ヘルプには、ProにもMaxにも「5時間ごとの上限」と「週ごとの上限」があると書かれています(Using Claude Code with your Pro or Max plan)。昼間にチャットでたくさん使うと、夕方にClaude Codeが止まることがあります。

請求で一番多い落とし穴は、環境変数 ANTHROPIC_API_KEY です。 公式ヘルプによると、この変数がパソコンに設定されていると、Claude Codeはプランの代わりにそのAPIキーで認証します。そうなると、Proに入っていてもAPIの料金が別にかかります(同じヘルプページ)。直し方は次の2つです。

  • Mac・Linuxでは、ターミナルで echo $ANTHROPIC_API_KEY と打ち、何か表示されたら、そのキーを設定している行(~/.zshrc などの設定ファイル)を消す
  • Claude Codeの中で /login と打ち、サブスクリプションのアカウントでログインし直す

Claude Codeのインストール方法(Mac/Windows)

公式がすすめるのは「Native Install」で、ターミナルに1行貼るだけで入ります。Node.jsは要りません。

先に動く環境を確かめておきます。公式の動作条件は、macOS 13.0以上、Windows 10 1809以上かWindows Server 2019以上、Ubuntu 20.04以上、Debian 10以上、Alpine Linux 3.19以上です。メモリは4GB以上、ネット接続も必要です(Advanced setup・2026年10月時点)。

Macの手順

  1. 「アプリケーション」→「ユーティリティ」→「ターミナル」を開く
  2. 次の1行を貼って、Enterを押す

curl -fsSL https://claude.ai/install.sh | bash

  1. 途中で進み具合は表示されません(公式にもそう書かれています)。終わるまで待ちます
  2. ターミナルのウィンドウを新しく開き直して、claude --version と打つ
  3. 2.1.211 (Claude Code) のように番号が出れば入っています

Homebrewを使っている人は brew install --cask claude-code でも入ります。ただしこの方法は自動で更新されないので、ときどき brew upgrade claude-code を打ってください。

Windowsの手順

最初に、開いている画面がPowerShellかCMD(コマンドプロンプト)かを見分けます。行の先頭が PS C:\ ならPowerShell、PS が無く C:\ ならCMDです。

  1. スタートメニューで「PowerShell」を検索して開く(管理者として実行しなくてよい)
  2. PowerShellなら irm https://claude.ai/install.ps1 | iex を貼ってEnter
  3. CMDなら curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd を貼ってEnter
  4. 新しいウィンドウを開いて claude --version を打つ

WinGetを使う人は winget install Anthropic.ClaudeCode でも入ります。こちらも自動では更新されません。

あわせてGit for Windowsを入れておくのもおすすめです。入っていないとClaude CodeはPowerShellでコマンドを動かし、入っていればGit Bashを使います。公式では「必須ではない」扱いです。

claude code vscode 使い方 無料

VS Code拡張は無料で入れられます。ただ、動かすにはターミナル版と同じ有料の契約かConsoleのアカウントが要ります。拡張機能に別料金はかかりません。

「any paid Claude subscription (Pro, Max, Team, or Enterprise) or a Claude Console account works, and no API key is required.」(Use Claude Code in VS Code)

訳: 有料のClaudeプラン(Pro・Max・Team・Enterprise)かClaude Consoleのアカウントがあれば使えます。APIキーは要りません。

VS Codeに入れる手順

  1. VS Codeが1.94.0以上か確かめる(メニューの「ヘルプ」→「バージョン情報」、Macは「Code」→「Visual Studio Codeについて」)
  2. 拡張機能の画面を開く(Macは Cmd+Shift+X、Windowsは Ctrl+Shift+X)
  3. 検索欄に「Claude Code」と入れ、提供元がAnthropicのものを選んで「Install」を押す
  4. コマンドパレットを開く(Macは Cmd+Shift+P、Windowsは Ctrl+Shift+P)
  5. 「Claude Code」と入れ、Open in New Tab を選ぶ
  6. 初めて開くとログインを求められるので、ProなどのアカウントかConsoleでログインする

以上の流れは公式の説明のとおりです。同じ拡張機能はエディタのCursorにも入れられます。

拡張の良い所は、Claudeが出した変更を差分(どこを足し、どこを消したか)で見ながら受け入れられることです。立てた計画を受け入れる前に直すこともできます。ターミナルが苦手な人にはこちらのほうが向いています。一方で、公式は全部の機能が使えるのはターミナル版(CLI)だとしています。細かい設定やスクリプトからの自動実行は、ターミナル版から触ることになります。

ログインできないときは、上で書いた ANTHROPIC_API_KEY の設定を疑ってください。VS Codeはパソコンの環境変数を引き継ぐので、そのキーでの請求になることがあります。

Claude ProプランとClaude Codeの料金プランの違い

Claude Codeだけの料金プランはありません。Claudeのプランに含まれていて、プランによって使える量が変わります。

Claude ProプランとClaude Codeの料金プランの違い
プラン月額(2026年10月時点)Claude Code向いている人注意点
Free0ドル使えないチャットだけでよい人Claude Codeは対象外
Pro月払い20ドル・年払いなら月17ドル使えるまず試す人・週に数回使う人5時間ごとと週ごとの上限がある。チャットと共有
Max 5x100ドル使える毎日数時間使う人使える量はProの5倍。月100ドル分のAPIクレジットはClaude Codeには使えない
Max 20x200ドル使えるほぼ一日中動かす人使える量はProの20倍。自分の作業量で元が取れるか見極めが要る
Team1人あたり年払いで月20ドル・月払いで月25ドル(Standard)使える5人前後からのチーム人ごとの枠はチャットやCoworkと共有。StandardとPremiumの2種類の席がある
Enterprise1人あたり年払いで月20ドル+使用量(20席から)使える大きな会社使った分の費用が別にかかる

出典: 料金ページ、Maxプランの説明、コスト管理。料金は変わるので、申し込む前に公式で確認してください。

上限に届いたときの選択肢は2つです。1つは時間を置いて回復を待つこと。もう1つは「usage credits(追加の利用枠)」をオンにして、超えた分を払うことです。Claude Codeの中で /usage-credits と打つと、claude.aiの「Settings > Usage」が開きます。そこで追加の利用枠のオン・オフと、月にいくらまで使うかの上限を決められます(Manage costs effectively)。追加の利用枠を使うと、知らないうちに費用が増えることもあります。最初は上限額を決めてからオンにしてください。

ProからMaxに上げるかどうかは、次を目安にすると決めやすいです。

  • 「You've hit your session limit」(5時間の上限)が週に何度も出て、仕事が止まる → Max 5xを検討
  • 週の上限(weekly limit)にも当たる → Max 20xか、作業のやり方を見直す
  • 上限に一度もかからない → Proのままでよい

上限に当たる回数は、/usage を打つと確かめられます。Pro以上なら、どの機能が使用量を多く食っているかの内訳も、直近24時間と7日で切り替えて見られます。

Claude Codeの料金はどのくらいかかるのか(使用量課金の目安)

Console(API)で使う場合は、読み書きした文字量(トークン)に応じた従量課金です。軽い使い方なら1回数十円程度、毎日しっかり使えば月に数万円になることもあります。

公式の単価は次のとおりです(100万トークンあたり・2026年10月時点)。

Claude Codeの料金はどのくらいかかるのか(使用量課金の目安)
モデル入力出力公式の説明
Claude Opus 5.54ドル20ドル長い時間かかるコーディングや知的作業向け
Claude Sonnet 5.52ドル10ドル速さと賢さのバランスが一番よい
Claude Haiku 5.50.10ドルから0.50ドルから大量・速さ重視の作業向け

出典: Models overview。一括処理(Batch API)は50%引きで、同じ内容を読み直すとき(キャッシュの読み込み)は大きく割り引かれます。

たとえば、Sonnet 5.5で入力100万トークン・出力10万トークンを使ったとします。キャッシュの割引を考えないと、2ドル+1ドルで3ドルです。これは単価から出したかけ算の例で、実際に測った数字ではありません。Claude Codeはやり取りのたびに会話の履歴とファイルの中身を送り直すので、入力トークンはすぐ増えます。

会社での実際の平均は、公式のコスト管理ページに出ています。

「the average cost is around $13 per developer per active day and $150-250 per developer per month」(Manage costs effectively)

訳: 平均の費用は、開発者1人が使った日1日あたり約13ドル、1か月あたり150〜250ドルです。

同じページには、利用者の90%は1日30ドル未満に収まっているとも書かれています。この数字は企業の開発者が仕事で使った場合です。個人がたまに使うなら、もっと少なくなるはずです。逆に言えば、毎日使うつもりならConsoleよりPro(月20ドル)やMax(月100ドル)のほうが安く上がる場合が多くなります。

費用を抑える方法は、公式に書かれているものから4つ紹介します。

  • 別の作業に移るときは /clear で会話をリセットする。古い話を送り続けずに済む
  • ふだんはSonnetを使い、難しい設計だけOpusにする(/model で切り替え)
  • プロジェクトの説明書 CLAUDE.md は200行以内に収める
  • 「このコードをよくして」のようなあいまいな頼み方をやめ、ファイル名と直したい所を書く

何も操作していなくても、裏の処理で少しトークンを使います。公式によれば、ふつうは1セッションあたり0.04ドル未満です。

Claude Codeの基本的な使い方(コマンド・初回タスクの例)

作業したいフォルダに移動して claude と打ち、あとは日本語で頼むだけです。最初は、読むだけの質問から始めると安心です。

公式クイックスタートは7つのステップでできています(Step 1のインストールからStep 7のいろいろな作業まで。Quickstart・2026-10-20に数えた)。この記事の手順もこの7段に合わせました。

  1. インストールする: 上の見出しの手順どおり
  2. 最初のセッションを始める: cd 作業フォルダの場所 で移動して claude。初めてのときはブラウザが開くので、ProかConsoleでログインする
  3. 質問する: たとえば「このフォルダには何が入っている?」「一番最初に動くファイルはどれ?」
  4. 小さな変更を頼む: たとえば「README.mdに使い方の段落を足して」。変更の前に確認が出たら、内容を読んで Yes を選ぶ
  5. Gitを使う: たとえば「変更したファイルを教えて」「わかりやすい説明をつけてコミットして」
  6. 不具合を直す・機能を足す: たとえば「空のフォームが送れてしまう不具合を直して」
  7. ほかの作業も試す: テストを書かせる、説明書を更新させる、変更を見直させる

公式の例は英語ですが、日本語で頼んでかまいません。

よくある質問

Claude Codeはスマホでも使えますか?

使えます。ただし、パソコンのターミナル版をそのまま動かすわけではありません。公式によると、Web版のClaude Code(claude.ai/code)はiOSとAndroidのClaudeアプリから使え、作業はクラウドで進みます。使うには有料のプランが要ります。

Claude Codeに無料トライアルはありますか?

2026-10-20時点の公式ドキュメントでは、Claude Code専用の無料トライアルは確認できませんでした。Freeプランは対象外と、公式にはっきり書かれています。費用を抑えて試すなら、Proを月払いで1か月だけ契約するか、Consoleで少額を前払いするのが現実的です。

Claude Codeを使うのにAPIキーは必須ですか?

必須ではありません。ProやMaxのアカウントでブラウザからログインすれば、APIキーは要りません。むしろ ANTHROPIC_API_KEY が設定されていると、プランではなくAPIの料金で請求されることがあるので気をつけてください。

Claude CodeとGitHub Copilotはどちらを選ぶべきですか?

エディタで書いている途中の補完がほしいならCopilot、フォルダ全体の調査や、複数のファイルの修正・テスト・コミットまでまとめて任せたいならClaude Codeが合います。会社ですでにどちらかを契約しているなら、まずそれを使い切るのが近道です。選ぶ基準はChatGPT Claude Copilot使い分けの基準で詳しく比べています。

ProとMaxで使えるClaude Codeの機能は違いますか?

公式ヘルプで分かる違いは、主に使える量です。Max 5xはProの5倍、Max 20xは20倍使えます。さらにMaxは毎月のAPIクレジットが付きますが、Claude Codeには使えません。

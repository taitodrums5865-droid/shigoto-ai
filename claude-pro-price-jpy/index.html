Claude Proの料金を日本円にすると、1ドル=158円なら月払いで約3,476円、年払いで約34,760円です。消費税10%を入れた額で、カード会社の手数料はまだ足していません(2026年10月時点・最新は公式で確認)。公式の価格は米ドルだけで、円での固定の値段はありません。カード会社が決めるレートで、そのつど円の額が決まります。iPhoneのApp Storeで払うなら、月額3,000円という円の固定価格になります。

この記事の要点

  • Proは月20ドル・年200ドル、日本では別に消費税10%が加わる
  • 1ドル158円なら月約3,476円、カード手数料でさらに変わる
  • 10か月以上使うなら年払いのほうがドル建てで安い

Claude Proの料金は日本円でいくらになる?

Claude Proは月20ドルです。日本では別に消費税10%が加わり、請求は22ドルになります。円の額は、カード会社のレートで決まります。

公式の料金ページの表示は次のとおりです。

「Per month with annual subscription discount ($200 billed up front). $20 if billed monthly.」(Claude Plans & Pricing)

訳: 年払いの割引を使うと月あたり17ドル(200ドルを先に一括で払う)。月払いなら20ドル。

同じページには「Prices shown don't include applicable tax.」(表示価格に税は含まない)とも書かれています(料金ページ)。日本の場合は、2026年4月1日から消費税10%が別に加わります。

「Starting April 1, 2026, 10% consumption tax will be added to all plan prices.」(Notice regarding consumption tax (JCT) for Japanese customers)

訳: 2026年4月1日から、すべてのプランの価格に消費税10%が加わります。

個人向けプランの料金(2026年10月時点)

公式の料金ページに載っている個人向けのプランは、Free・Pro・Max 5x・Max 20xの4つです(料金・2026-10-23に数えた)。円の額は、1ドル=158円(2026年10月21日のニューヨーク市場の終値158.14円を丸めた数字。みんかぶFX)と消費税10%で計算しています。

この表の円の額は、あくまで目安です。実際に払う額は、次の2つで変わります。

  1. 決済した日のレート(円安なら上がり、円高なら下がる)
  2. カード会社の海外事務手数料(1.60%〜3.63%など、カードによって違う)

「約3,000円」と書いてあるページとの違い

ほかの記事で「Pro月約3,000円」と見かけたなら、それは多くの場合、消費税が始まる前の数字か、1ドル=150円で計算した数字です。2026年4月から消費税が加わったので、20ドル×150円=3,000円という計算は、今のWebの支払いには合いません。

ただ、App Storeで払う場合は、話が別です。iPhoneのApp Storeでは、Claude Proの月払いが3,000円で売られています(App Store・2026年10月23日時点)。くわしくは支払い方法の見出しで比べます。

Claude Pro 料金 日本円 年間プランはいくら?

Webの年払いは220ドル(税込)で、1ドル158円なら約34,760円です。1回の請求で決まるので、その日のレートで1年分の円の額が決まります。

年払いの200ドルは、先に一括で払います(料金ページ)。消費税10%を足すと220ドル。月払いを12か月続けると264ドルなので、ドルの上では44ドルの差です。

年払いの1回の額は、月払いの約10か月分にあたります。

年払いで気をつけたいこと

年払いの弱点は、途中でやめたときです。Anthropicの利用規約には、次のように書かれています。

「Except as expressly provided in these Terms or where required by law, all payments are non-refundable.」(Consumer Terms of Service)

訳: 規約に書いてある場合と法律で必要な場合を除き、支払いは返金されません。

たとえば、3か月使って合わないと分かったとします。年払いだと、残りの9か月分は戻ってこないのが原則です。月払いなら、3か月分(66ドル)で済みました。だから、年払いを選ぶのは「1年続けると、ある程度見えている人」に向いています。

月払いと年払いでどちらが得か?

10か月以上使うなら年払いのほうが得です。ただ、円で見ると、為替の動き方しだいで差は少し広がったり縮んだりします。

ドルの上では、年払い220ドルは月払い22ドルのちょうど10か月分。11か月目と12か月目は、月払いと比べて実質0円になります。割引率は約17%(264ドル→220ドル)です。

円で見たときの差の広がり方

月払いは毎月その月のレートで、年払いは1回のレートで円の額が決まります。そのため、次のように動きます。

円で見たときの差の広がり方
この先の為替年払いと月払いの円の差
円安が進む(例: 158円→165円)年払いのほうが、さらに得になる(先に安いレートで払い終えているから)
ほぼ動かないドルの上の差(約17%)とほぼ同じ
円高が進む(例: 158円→145円)差が少し縮む(月払いの後半が安いレートで済むから)

円高が進んだ場合でも、年払いのほうが高くなるのは、レートが大きく動いたときだけです。たとえば、年払いを1ドル158円で払ったとします。月払いの12か月の合計が年払いと同じになるのは、月払いの平均レートが約132円(158円×220÷264)まで円高になったときです。1年でそこまで動くことは、よくあることではありません。

判断の基準

  • 「毎日の仕事で使う」と決まっている → 年払い
  • 「試しに使う」「来月どうなるか分からない」 → 月払い
  • 迷うなら → 月払いで1〜2か月使ってから、年払いへ替える

つまずきやすいのは、月払いから年払いへ替える時期です。Claudeには、請求日を直接変える方法がありません(Paid plan billing FAQs)。替えるときの手順や、替えたあとの請求のされ方は、Settings > Billingの画面や公式ヘルプで、その時点の案内を確かめてから進めてください。

カード決済で実際に請求される日本円額はどう決まる?

請求額は「ドルの額 ×(国際ブランドなどが決めたレート + カード会社の手数料)」で決まります。手数料はカードによって違い、1.60%のものもあれば3.63%のものもあります。

Webで払うClaude Proは、ドルのまま請求されます。日本向けの消費税のお知らせにも、請求の通貨は変わらないと書かれています。

「Your billing currency remains unchanged.」(JCTのお知らせ)

訳: 請求の通貨は変わりません。

円に直すのは、カード会社の仕事です。

JCBは、海外の加盟店などに支払いの処理をした日の基準レートに1.60%を足して、円に直します(JCB)。JCBブランドでも、ほかの会社が発行する提携カードは、その会社の率になります。楽天カードのページにも、国際ブランドが決めたレートに手数料を足して明細に書く、とあります。換算レートは、現地で使ったときのレートではない、とも書かれています(楽天カード)。

自分のカードの請求額を計算する手順

  1. 自分のカードの発行会社(券面に書いてある会社名)を確かめる
  2. 発行会社のサイトで「海外事務手数料」または「海外利用 換算レート」と書かれたページを開き、率をメモする
  3. 22ドル(月払い)または220ドル(年払い)に、その日のドル円レートを掛ける
  4. 3の答えに「1+手数料率」を掛ける

たとえば、手数料3.63%のカードで、1ドル158円の月払いの場合。22×158=3,476円、3,476×1.0363≒3,602円です。

つまずきやすい所

  • 明細の額が、決済した日のレートと合わない: 円に直す日は、カード会社がお店側との処理をした日です。Claudeから決済のメールが来た日とずれることがあります
  • デビットカードで引き落とし額と確定額が違う: デビットカードは、使ったときに仮の額を引き落とし、あとで確定した額との差を調整する仕組みのことがあります。くわしくは、発行している銀行の案内を見てください
  • カード明細に「CLAUDE.AI」などのなじみのない名前がある: 英語の加盟店名で出ることがあります。Settings > Billingの請求書の日付と額で照らし合わせると、すぐ分かります

為替レートの変動で毎月の請求額が変わるのはなぜか?

ドルで決まった額を、毎月ちがうレートで円に直しているからです。Anthropicが値上げしたわけではありません。

月払いの22ドルは、毎月同じです。変わるのは、円に直すときのレートだけ。1ドルが何円かで、請求額は次のように動きます。

本当の値上げとの見分け方

請求額が上がったとき、理由は次の3つのどれかです。

  1. 為替: ドルの額は22ドルのまま、円の額だけ変わった
  2. 消費税: 2026年4月1日の請求から、10%が足されている(JCTのお知らせ)
  3. 価格の改定: ドルの額そのものが上がった

3の場合は、事前に知らせがあります。利用規約には、料金が上がるときは少なくとも30日前に知らせる、と書かれています(Consumer Terms of Service)。

見分けるには、Settings > Billingで請求書を開き、ドルの額を見ます。請求書は、請求先のメールアドレスにも自動で届きます。画面では、見たい請求書の横の「View」を押して開きます(Paid plan billing FAQs)。ドルの額が22ドルのままなら、変わったのはレートです。

Claude Code Proの料金は日本円でいくら?

「Claude Code Pro」という別のプランはありません。Claude Proの月20ドル(日本は税込22ドル)の中に、Claude Codeが入っています。

公式ヘルプの説明はこうです。

「With Pro and Max plans, you now have access to both Claude on the web, desktop, and mobile apps and Claude Code in your terminal with one unified subscription.」(Use Claude Code with your Pro or Max plan)

訳: ProとMaxでは、Web・デスクトップ・スマホのClaudeと、ターミナルで動くClaude Codeを、1つの契約で使えます。

料金ページでも、ProにClaude Codeが含まれると書かれています(料金)。なので、円の額はClaude Proと同じ。1ドル158円なら、月払いで約3,476円です。

別にお金がかかるのはどんなとき?

使える量の上限に届いたときです。公式ヘルプによると、上限に届くとAPIクレジットを使う選択肢が出ることがあります。それを選ぶと、プランとは別に、APIの通常料金で請求されます(公式ヘルプ)。

  • 向いている人: 1日に数回、小さな修正や調べものにClaude Codeを使う人。Proの範囲で収まりやすい使い方です
  • 向いていない人: 一日中Claude Codeを動かし続ける人。上限に何度も当たるなら、Max 5x(月100ドル・税込110ドル、1ドル158円なら約17,380円)も考えてください
  • 注意点: Claudeの画面とClaude Codeは、同じ使用量の枠を分け合います。チャットをたくさん使った日は、Claude Codeで使える分も減ります

Claude Codeの入れ方と、無料でどこまでできるかは、Claude Code使い方|無料の範囲と料金表・導入7手順にまとめています。

Claude Pro料金の支払い方法にはどんな選択肢があるか?

Webで申し込むなら、クレジットカードかデビットカードだけです。iPhoneやAndroidのアプリから申し込むと、App StoreやGoogle Playの支払い方法になります。

「For subscriptions purchased on the web, we only accept credit or debit cards.」(Paid plan billing FAQs)

訳: Webで申し込む契約は、クレジットカードかデビットカードしか使えません。

Webで払うか、App Storeで払うか

App Storeでは、Claude Proに円の固定価格がついています。App StoreのClaudeのページに載っているApp内課金は4つです(App Store・2026-10-23に数えた)。

  • App Storeが向いていない人: 会社の経費で落とすので、Anthropicの請求書が必要な人。Maxを使う人

Webでカードを登録・変更する手順

公式ヘルプの手順です(Paid plan billing FAQs)。画面の言葉は英語の表記で書きます。日本語表示では「設定」など、訳した言葉で出ることがあります。

  1. claude.aiにログインし、Settings > Billingを開く
  2. 支払い方法の横にある「Update」を押す
  3. 新しいカードの情報を入れる
  4. 「Update」を押して保存する

新しいカードが、次からの更新の支払いに使われます。

やめるときの手順

Webかデスクトップアプリで申し込んだ場合は、こうです(Cancel your Pro or Max subscription)。

  1. ブラウザかデスクトップアプリでログインする
  2. 左下の自分の名前(イニシャル)を押し、「Settings」を選ぶ
  3. Billingを開き、「Cancel」を押す

iPhoneやAndroidのアプリで申し込んだ場合は、次の手順です。

  1. 右上のイニシャルを押す
  2. 「Billing」を選ぶ
  3. 「Manage subscription」を選び、案内に沿って進める

やめても、今払っている期間が終わるまでは有料プランを使えます。次の請求を止めたいなら、次の請求日の24時間以上前に手続きしてください(同じ出典)。

つまずきやすい所

  • カードが通らない: 海外の利用を止めているカードや、ネットでの海外決済の本人確認が必要なカードがあります。カード会社のアプリで海外利用の設定と本人確認(3Dセキュア)の登録を確かめてください
  • PayPalを探しても見つからない: Webの契約は、公式ヘルプではカードだけと書かれています
  • 請求日を変えたい: 直接変える方法はありません。いったん解約して、また申し込むと新しい請求日になります(Paid plan billing FAQs)

よくある質問

claude pro 料金 日本円 年間はどれくらい変わるのか

年払いは税込220ドルを1回で払うので、1ドルが10円動くと約2,200円変わります。たとえば150円なら33,000円、165円なら36,300円です(カード会社の手数料は別)。月払いを12か月続けた場合と比べると、ドルの上では44ドル安くなります(2026年10月時点)。

claude code pro 料金 日本円は別途かかるのか

かかりません。Claude CodeはProの月20ドル(日本は税込22ドル)に入っています(公式ヘルプ)。ただし、使える量の上限に届いたあとでAPIクレジットを使うと決めた場合は、APIの料金が別に請求されます。

Claude Proの料金は消費税が別にかかるのか

かかります。2026年4月1日から、日本の利用者にはすべてのプランの価格に消費税10%が足されています(JCTのお知らせ)。請求の通貨はドルのままで、消費税の額は請求書に円でも書かれます。

解約した場合、日本円での返金はあるのか

原則、返金はありません。利用規約には、規約に書いてある場合と法律で必要な場合を除いて、支払いは返金しないとあります(Consumer Terms of Service)。やめても、払った期間の終わりまでは有料プランを使えます(公式ヘルプ)。

App Storeで払うのとWebで払うのはどちらが安い?

2026年10月23日時点では、Proの月払いはApp Storeの3,000円のほうが、Web(1ドル158円で約3,476円〜)より安くなっています。年払いはApp Storeが35,000円で、Webとほぼ同じです。ただ、どちらの価格も変わることがあり、為替が円高に動けばWebのほうが安くなることもあります。

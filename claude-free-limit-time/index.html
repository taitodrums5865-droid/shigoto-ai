Claudeの無料プランには、5時間ごとにリセットされる「セッション上限」があります。「1日○回まで」という決まった回数はありません。Anthropicは、送れるメッセージ数は混み具合で変わると説明しています（Get started with Claude・2026年10月時点）。上限に届いたら、次のリセットまで待つか、Pro（月20ドル）に切り替えるかを選びます。

「While using the free Claude plan, there is a session-based usage limit that will reset every five hours.」（Get started with Claude）

訳: 無料のClaudeプランには、5時間ごとにリセットされるセッション単位の利用上限があります。

この記事の要点

  • 無料の上限は5時間ごとにリセット。回数は非公開
  • Proは5時間あたり無料の少なくとも5倍使える
  • 上限が週2回以上ならPro、月1回以下なら無料のまま

向いている人: Claudeを無料で使っていて上限に困り始めた人

あなたに合うのはどれ?

上限に届く回数と、待たされたときに困るかどうかで決めます。ここでの「週2回」などの数字は、このサイトが判断のために置いた目安です。Anthropicの公式な基準ではありません。

理由は1行ずつです。

  • 初めての人: 無料でもWeb検索・ファイル作成・Artifacts・プロジェクト5個まで使えるので、まず上限を体感してからで遅くありません（料金）。
  • 月1回以下の人: 5時間待てば元に戻るため、月20ドルを払う理由がまだ弱い状態です。
  • 週2回以上の人: 待ち時間が仕事の段取りを崩し始めるので、1日あたり約1ドル（20ドル÷20営業日）なら元が取れやすくなります。
  • Proでも足りない人: MaxはProの5倍か20倍の量を5時間ごとに使えます（料金）。

料金はすべて2026年10月時点のものです。最新の金額は公式で確かめてください。日本円でいくら引き落とされるかは Claude Pro料金|日本円の実額を月払い・年払い別に表で にまとめています。

Claude無料プランのメッセージ制限は何回まで?

決まった回数はありません。公式は「混み具合によって変わる」とだけ説明しています。

Anthropicのヘルプの原文はこうです。

「The number of messages you can send will vary based on demand」（Get started with Claude）

訳: 送れるメッセージの数は、需要（混み具合）によって変わります。

同じヘルプには、すべての人が公平に使えるように「ほかの種類の利用上限を設けることがある」とも書かれています。数字は公表されていません。ネット上で見かける「15〜40回」「数十回」といった数字は、各サイトが独自に出した目安です。Anthropicの数字ではない点に気をつけてください。

回数が決まらないのは、1通ごとの「重さ」が違うからです。たとえば「この一文を丁寧語にして」という短い依頼と、「添付した30ページのPDFを要約して、表にまとめて」という依頼は、どちらも1通として数えられます。それでも、使う量はまったく違います。何が重くなるかは、下の「## Claude無料の制限は何を基準に決まる?」で詳しく説明します。

つまずきやすい所: 「昨日は30回送れたのに今日は少ない」

これは故障ではありません。混んでいる時間帯は送れる量が減ることがある、と公式に書かれています。長い会話を続けた日や、ファイルをたくさん添付した日も、早く上限に届きます。昨日と今日を回数で比べるより、「1回の上限に届くまでにどんな作業をしたか」を見るほうが、Proに切り替えるかどうかを決めやすくなります。

Claude無料の制限は何時間でリセットされる?

5時間です。無料プランのセッション上限は、5時間ごとに元に戻ります（Get started with Claude）。

Web検索のヘルプにも、同じ内容がはっきり書かれています。

「As a free user, you have usage limits that reset every five hours.」（Enable and use web search）

訳: 無料ユーザーの利用上限は、5時間ごとにリセットされます。

「毎日0時にリセット」ではない

ここがいちばん誤解されやすい所です。公式の言い方は「session-based（セッション単位）」で、日付が変わったときに戻る仕組みではありません。上限に届くと「5-hour limit reached - resets [time]」という表示が出て、[time]の部分に次に使える時刻が入ります（Troubleshoot Claude error messages）。いつ戻るかは、自分で計算するより、この表示の時刻を見るのが確実です。

週ごとの上限はある?

有料プランには、5時間のセッション上限とは別に「週の上限」があります。毎週決まった時刻にリセットされます（What is the Pro plan?・How do usage and length limits work?）。無料プランのヘルプで説明されているのは5時間のセッション上限だけです。ただし、先ほどの「ほかの種類の上限を設けることがある」という一文があります。無料なら週の上限は絶対に無い、とまでは言い切れません。

Claude無料で制限に達するとどうなる?

新しいメッセージを送れなくなり、次に使える時刻が表示されます。

公式のエラー一覧に載っている、上限についての表示は次の2つです（Troubleshoot Claude error messages・英語表示の原文）。

Claude無料で制限に達するとどうなる?
表示意味直し方
5-hour limit reached - resets [time]5時間の枠を使い切った表示の時刻まで待つ。有料プランなら利用クレジットも使える
You've reached your weekly limit. It resets [day] at [time].週の上限に届いた表示の曜日・時刻まで待つ

上限とまちがえやすい表示が、ほかに2つあります。

  1. 「Your message will exceed the length limit for this chat. Try attaching fewer or smaller files or starting a new conversation.」

これは利用上限ではなく、その1つのチャットに入る長さの上限です。待っても直りません。添付ファイルを減らすか小さくする、新しい会話を始める、要点だけを先にまとめてから送る、のどれかで直ります。

  1. 「Due to unexpected capacity constraints, Claude is unable to respond to your message. Please try again soon.」

一時的に混んでいるという表示で、あなたの上限とは関係ありません。公式は、数分おいてもう一度送るよう案内しています。全体の障害かどうかは status.claude.com で確かめられます。

つまずきやすい所: 待ち時間に別のAIへ移ると、続きが途切れる

上限に届いても、それまでの会話は消えません。リセット後に同じチャットを開けば、続きから頼めます。待つあいだにChatGPTなどへ移る人もいますが、それまでの前提をもう一度説明し直すことになります。どの道具を何に使うかは ChatGPT・Claude・Copilot使い分け|料金と用途の比較表 を参考にしてください。

Claude無料とProの制限はどう違う?

Proは、5時間のセッションあたり無料の少なくとも5倍使えます。上位のモデルや、Claude Codeも使えるようになります。

公式の料金ページの書き方は次のとおりです。

「at least 5x more usage per 5-hour session than Free」（Claude 料金）

訳: 5時間のセッションあたり、無料より少なくとも5倍多く使えます。

公式の料金ページを数えると、個人と組織向けに載っているプランは Free・Pro・Max・Team・Enterprise の5つでした。日本語の料金ページで無料プランに挙げられている機能は6項目です（料金・2026-10-28に数えた）。チャット、Web検索、メモリ、Artifactsなど、試すのに十分な機能は無料にもそろっています。無料とProの差は、機能の有無より使える量のほうが大きい、と言えます。

Proの注意点: 「無制限」ではない

Proにも5時間の上限と週の上限があります（What is the Pro plan?）。「お金を払えば好きなだけ使える」と思って切り替えると、長いファイルを毎日読ませる使い方ではPro でも上限に届きます。Proで上限に届いたときは、利用クレジット（量に応じた追加の支払い）を有効にすれば、そのまま使い続けられます（Manage usage credits）。この利用クレジットは有料プランだけの機能です。無料プランでは使えません。

Proが向いている人: 平日ほぼ毎日Claudeで資料作成・文章の直し・要約をしていて、待ち時間で作業が止まる人。Opusや Claude Code も使いたい人。 Proが向いていない人: 週に数回、短い質問をするだけの人。上限に届いたことが無い人には、5倍の量は使い道がありません。

Claude無料の制限は何を基準に決まる?

送った回数ではなく、使った量で決まります。会話の長さと複雑さ、使う機能、モデル、努力レベル（effort）の4つで量が変わります。

公式ヘルプは、使う量に影響するものとして次を挙げています（How do usage and length limits work?）。

「the length and complexity of your conversations, the features you use, which Claude model you're chatting with, and the effort level you've selected」

訳: 会話の長さと複雑さ、使っている機能、どのClaudeモデルと話しているか、選んだ努力レベル。

これを、無料プランでよくある場面に当てはめてみます。

Claude無料の制限は何を基準に決まる?
量が増えるものなぜ増えるかたとえば
長い会話Claudeは返事のたびに、それまでの会話も読み直す朝から同じチャットで50往復している
添付ファイルファイルの中身もすべて読む50ページの報告書PDFを毎回添付し直す
Web検索・Webページの読み込み検索結果や記事の本文を読む分が加わる。公式も上限に数えると明記（Web検索のヘルプ）長い記事のURLを貼って「要約して」と頼む
ツール・コネクタ公式いわく「Tools and connectors are token-intensive」（量を多く使う）使っていない連携をオンにしたまま
拡張思考・高い努力レベル答える前に長く考える分だけ増える簡単な言い換えに拡張思考をオンのまま

公式は、Web検索のヘルプでも「長い記事へのリンクを直接貼ると、上限のかなりの部分を使うことがある」と注意しています（Enable and use web search）。

つまずきやすい所: 長い1つのチャットを使い続ける

会話が長くなるほど、1往復ごとの量が増えていきます。話題が変わったら新しいチャットを始めるだけで、同じ5時間で頼める回数が増えやすくなります。前の会話の結論が必要なら、「ここまでの決定事項を5行でまとめて」と頼みます。その5行を新しいチャットの最初に貼れば、前提を引き継げます。

Claude無料の制限時間を増やす方法はある?

無料のまま上限そのものを増やす公式の方法はありません。できるのは、同じ上限の中で使う量を減らすことです。

上限に届いたときに公式が案内している選択肢は、「リセットを待つ」「プランを上げる」「利用クレジットを買う」の3つです（How do usage and length limits work?）。このうち利用クレジットは、Pro・Max 5x・Max 20xが対象と書かれています（Manage usage credits）。無料プランで使えるのは「待つ」と「節約する」の2つです。

もう1つ、「Limit reset」という機能があります。使うとすぐに5時間の上限か週の上限が満タンに戻るもので、対象のプランにときどき配られます。「Settings > Usage」の「Reset for free」から使います（What is a limit reset?）。ただ、どのプランが対象かはヘルプに書かれていません。無料プランで必ずもらえるものではない、と考えておくのが安全です。

無料のまま使える量を増やす手順

公式の「Usage limit best practices」と「How do usage and length limits work?」に書かれている方法を、無料プランで使える形に並べ直しました。

  1. 送る前に、質問をまとめる。 関係する質問は1通にまとめます。たとえば「この文を短くして」「次に敬語にして」「最後に件名をつけて」を3回に分けず、「次の文を①短く②敬語にし③件名を1つつけて」と1回で頼みます。
  2. 指示を具体的に書く。 「いい感じに直して」だと何度もやり直しになります。「200字以内・取引先あて・結論を先に」のように条件をつけると、1回で終わりやすくなります。
  3. 送る前に見直す。 書き足しの往復を減らせます。
  4. 使わないツールを切る。 検索が要らない作業では、Web検索や連携をオフにします。
  5. 簡単な作業では拡張思考を切る。 言い換え・誤字直しのような作業に、長い思考は要りません。
  6. 何度も使う資料はプロジェクトに入れる。 公式によると、プロジェクトの資料はキャッシュ（一時保存）されているあいだにもう一度参照すると、上限への数え方が少なくなります。無料でもプロジェクトは5個まで作れます（料金）。作り方は Claudeプロジェクト使い方|作成から共有まで5手順と比較表 で説明しています。
  7. プロジェクトの不要なファイルを消す。 使わないファイルが入ったままだと、そのたびに読まれる量が増えます。

つまずきやすい所: アカウントを複数作って回す

上限を避けるためにアカウントを何個も作るやり方は、公式の案内にはありません。仕事のデータが別々のアカウントに散らばり、あとで探せなくなります。そこまで必要になったら、それがProに切り替える合図です。

Claude無料からProに切替える判断基準は?

上限に届くのが週2回以上で、待ち時間に仕事が止まるならProに切り替えます。月1回以下なら無料のままで十分です。

この「週2回」は、このサイトが判断のために置いた目安です。Anthropicの基準ではありません。根拠は次の計算です。

  • Proは月20ドル。月の営業日を20日とすると、1日あたり約1ドルです（2026年10月時点・年払いなら月17ドル相当で約0.85ドル）。
  • 上限に届くと、最長で5時間待つことになります。平日の昼に届けば、その日の午後の作業が丸ごと止まりかねません。
  • 週2回届くなら、月に8回ほど仕事が止まる計算です。1回あたりに直すと2.5ドルほどになります。

月1回以下夜や休日なら困らない無料のまま＋節約の手順
週1回くらい締め切りの日だけ困る節約の手順を1週間試し、それでも届くならPro

頻度のほかに、次のどれかに当てはまる場合も、Proを考えるきっかけになります。

  • Opusを使いたい。 無料で使えるのはSonnetとHaikuで、Opusは Pro以上です（料金）。
  • Claude Codeを使いたい。 Claude CodeはProから含まれます（料金）。無料で使える範囲は Claude Code使い方|無料の範囲と料金表・導入7手順 にまとめています。
  • 上限に届いたあとも、お金を払ってでも続けたい日がある。 利用クレジットは有料プランだけで使えます。

Proに切り替える手順

公式ヘルプが案内している入口は、Webの claude.ai/upgrade と、スマホのアプリストアの2つです（What is the Pro plan?）。

  1. パソコンのブラウザで claude.ai にログインします。
  2. claude.ai/upgrade を開きます。
  3. Proを選び、月払いか年払いかを選びます。
  4. 支払い情報を入れて申し込みます。
  5. 切り替わったら「Settings > Usage」を開き、5時間の上限と週の上限の進み具合がバーで出ているか確かめます（Usage limit best practices）。

つまずきやすいのは支払い先です。iPhoneやAndroidのアプリから申し込むと、支払いはApple・Googleのストア経由になります。ストアでの価格はWebと違うことがあります。公式も、地域ごとの価格はアプリストアで確かめるよう書いています。どこで申し込んだかによって解約する場所も変わるので、申し込んだ入口をメモしておきましょう。円での実額は Claude Pro料金|日本円の実額を月払い・年払い別に表で で比べられます。

Claude無料の制限はアプリとWeb版で違う?

違いません。上限はアカウント単位で、Web・デスクトップ・スマホのどれから送っても同じ枠を使います。

無料プランでは、Web・デスクトップ・モバイルのどれでもチャットできます（料金）。ヘルプには、アプリごとに別の枠がある、という説明はありません。有料プランについては、もっとはっきり書かれています。

「These limits are shared across Claude and Claude Code, meaning all activity in both tools counts against the same limits.」（Using Claude Code with your Pro or Max plan）

訳: これらの上限はClaudeとClaude Codeで共通です。両方での利用は、すべて同じ上限に数えられます。

つまずきやすい所: スマホに切り替えれば続けられると思う

たとえば、パソコンのブラウザで上限に届いたあとに、スマホのアプリを開いても、同じアカウントなら同じ時刻まで待つことになります。今どのモデルで話しているかは、Webとデスクトップでは入力欄の下、スマホでは画面の上に出ています（Get started with Claude）。

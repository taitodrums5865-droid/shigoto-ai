#ChatGPT #Claude #生成AI #Claude Code

ChatGPT・Claude・Copilotは、仕事の場面ごとに1つ選ぶと迷いません。資料作成ならChatGPT、社内のメールやファイルを参照するならMicrosoft 365 Copilot（Premium）、複数のファイルにまたがるコードを書くならClaude（Claude Code）です。料金と機能は2026年10月22日時点の公式ページで確認した内容です。よく変わるので、契約前には必ず公式ページを見てください。

この記事の要点

  • 資料作成はChatGPT、社内データ参照はMicrosoft 365 Copilot、複数ファイルのコードはClaude Codeを推奨
  • Copilotが社内データを自動で参照するのはPremium（アドオン）だけで、範囲はユーザーの権限内
  • Claude Codeは有料プランのみ。無料で試せるのはChatGPTとClaudeのチャット

向いている人: 業務でAIツールの使い分けに迷う会社員・管理職・個人事業主

あなたに合うのはどれ?

答えは「会社が何を契約しているか」と「いちばん時間を取られている作業」で決まります。次の中から、自分に近いものを選んでください。

  • 会社でMicrosoft 365を使い、Copilotのアドオンが入っている → 社内情報を探す作業はMicrosoft 365 Copilotを使います。社外向けの資料を作るときにChatGPTを使ってよいかは、社内ルールで確認してください。
  • 会社でMicrosoft 365を使っているが、Copilotのアドオンは入っていない → 無料のCopilot Chatは社内データを自動では参照しません。社内情報を使いたいなら、アドオンを入れるかどうかを情報システム担当と相談しましょう。
  • Google WorkspaceやSlackが中心の会社 → ChatGPT Businessの「company knowledge」が候補になります。
  • 個人事業主で、提案書や報告書を作ることが多い → まずChatGPTの無料プランで試します。
  • 個人事業主・会社員で、Webサイトや業務ツールを自分で作る → Claude Pro（月額20ドル。2026年10月時点）でClaude Codeから始めます。
  • プログラミングはしない。文章の相談や要約が中心 → ChatGPTとClaudeは、どちらも無料プランで十分に試せます。最初から有料プランを契約する必要はありません。

結論：業務シーン別の「1つに絞った」選び方

各社が公式に「得意」と説明している機能をもとに、その作業で最初に開くツールを1つに絞ると次のようになります。3つとも今は「ひと通り何でもできる」サービスなので、機能の一覧を比べるより、場面で分けるほうが判断しやすくなります。

結論：業務シーン別の「1つに絞った」選び方
業務シーン選ぶツール公式情報から見た主な理由向いていない人

3つのサービスの基本をおさえる

3つとも有料プランは月額20ドル前後からです（2026年10月22日時点）。ただし、Microsoft 365 Copilotは会社のMicrosoft 365に「追加する」形の製品なので、個人向けの2つとは買い方が違います。

ChatGPT（OpenAI）

ChatGPTはOpenAIの対話型AIで、無料プランから使えます（ChatGPT Free Tier FAQ）。2026年10月時点の料金は次のとおりです。

  • 個人向けの「Plus」：月額20ドル（What is ChatGPT Plus?）
  • 上位の「Pro」：月額100ドル・200ドル・500ドルの3種類（About ChatGPT Pro tiers）
  • 法人向けの「ChatGPT Business」：標準シートが年払いで1ユーザー月額20ドル、月払いで25ドル（ChatGPT Business: General FAQ）

注意点：個人のアカウントに会社の機密情報を入れるのは避けてください。仕事で使うなら、会社が契約しているBusinessなどの法人プランを使うのが前提です。

👉 ChatGPTを無料で試す（公式）

Claude（Anthropic）

ClaudeはAnthropicの対話型AIです。公式の料金ページによると、無料プランでもWeb検索、ファイル作成、コード実行、メモリー、アプリ連携、Artifactsを使えます（Claude Pricing）。2026年10月時点の料金は次のとおりです（Claude Pricing）。

  • 「Pro」：月払いで月額20ドル（年払いなら月あたり17ドル）
  • 「Max」：月額100ドルから（利用枠はProの5倍または20倍）
  • 「Team」（2〜150人）：標準シートが年払いで月額20ドル（月払いで25ドル）、プレミアムシートが年払いで月額100ドル（月払いで125ドル）

Claude Codeは有料プラン（Pro・Max・Team・Enterprise）にすべて含まれていますが、無料プランでは使えません。一度に扱える情報量（コンテキストウィンドウ）は「最大100万トークン（モデルによる）」と案内されています（Claude Pricing）。

注意点：Claude Codeを試すには有料プランが必要です。「お金をかけずにコードを書くAIを試したい」という人には向きません。

👉 Claudeを無料で試す（公式）

Microsoft 365 Copilot（Microsoft）

「Copilot」という名前のサービスはいくつもあります。この記事で取り上げるのは、会社のWord・Excel・PowerPoint・Outlook・Teamsで使うMicrosoft 365 Copilotです。公式ドキュメントでは、ライセンスによって次の段階に分けられています（What is Microsoft Copilot? | Microsoft Learn）。

Microsoft 365 Copilot（Microsoft）
ライセンスできることの範囲
Copilot Chat（Basic）条件を満たすMicrosoft 365ライセンスに含まれる。Webの情報を使うチャットが中心。社内の文書は、アップロードするなどして自分で渡す必要がある
Microsoft 365 Copilot（Basic）アドオンはないが、Word・Excel・PowerPoint・OneNoteのCopilotを「標準アクセス」で使える。混み具合によって使えるかどうかが変わる
Microsoft 365 Copilot（Premium）アドオンのライセンスあり。Microsoft GraphとWork IQを通じて、メール・ファイル・会議・予定表などの社内データを自動で参照する。優先アクセスもつく
従量課金の機能Premiumのライセンスが前提。作業を代わりに進める「Copilot Cowork」や、コード向けの「Copilot Code」（Frontierプログラムで提供）を使った分だけ支払う

日本の公式料金ページでは、中小企業向けアドオン「Microsoft 365 Copilot Business」の価格が次のように表示されています（Microsoft 365 Copilot プランと価格、2026年10月22日に確認）。

  • 年払い：通常は1ユーザー月額3,148円相当。2026年7月1日〜12月31日のキャンペーン価格は2,698円相当（初年度のみ）
  • 月払い：1ユーザー月額3,778円

なお、プログラミング向けの「GitHub Copilot」は、Microsoft 365 Copilotとは別に契約する製品です（What is Microsoft Copilot? | Microsoft Learn）。また、公式ドキュメントでは、アプリの名前が「Microsoft 365 Copilot Chat」から「Microsoft Copilot Chat」に変わったと案内されています。

注意点：Microsoft 365を使っていない会社や、個人で仕事をしている人には向きません。

資料作成ならChatGPTを選ぶ

資料作成でChatGPTを選ぶのは、文書・表・スライドを編集できるファイルとして作れることを、公式ヘルプが正面から説明しているからです。

選ぶ理由：完成したファイルとして受け取れる

OpenAIは「ChatGPT Work」を、時間のかかる作業向けのエージェントとして説明しています。調べものや分析をしたうえで、文書・スプレッドシート・プレゼン資料・レポートを編集できるファイルとして作ります。指示文だけでなく、元になる資料や手持ちのテンプレートから作ることもできます（Creating and editing documents, spreadsheets, and presentations with ChatGPT Work）。

公式ヘルプの説明に沿うと、手順は次の3つです。

  1. Workを開き、作りたいファイルと使い道を書く（例：「社外向けの提案書。10枚程度のスライド」）
  2. 材料になる資料（市場調査のメモ、前回の提案書など）を添付する
  3. 出力の形式と、ファイルを作る場所を指定する

よく使う形式はテンプレートとして保存し、次から使い回せます。

Office・Googleのファイルとのつながり

関係するアプリを有効にすれば、GoogleドキュメントやGoogleスプレッドシート、Googleスライドの形式でも作れます。デスクトップアプリでは、ChatGPT for Excelのアドインを使ってExcelにも対応します（ChatGPT Work のヘルプ）。

PowerPointの中で使える「ChatGPT for PowerPoint」もあります。2026年7月6日にBusinessワークスペース向けの一般提供が始まりました。スライドの構成を崩さずに、資料の下書きを作ったり手直ししたりできます（ChatGPT for PowerPoint、ChatGPT Business release notes）。

こんな場合はCopilotでもよい

会社がすでにMicrosoft 365 Copilotを契約していて、社内のメールや過去の資料をもとに資料を作るなら、Copilotのほうが手間は少なくなります。WordやPowerPointのCopilotは、アドオンのない（Basic）ライセンスでも「標準アクセス」で使えます。Wordでは下書き・書き直し・要約、PowerPointではプロンプトや既存の資料からのスライド作成ができます（What is Microsoft Copilot? | Microsoft Learn）。

迷ったときは、次の基準で決めてください。

  • 材料は自分で用意して、形の整った資料に仕上げたい → ChatGPT
  • 材料が社内のメールやSharePointに散らばっている → Microsoft 365 Copilot（Premium）

向いていない人：会社が外部のAIサービスを禁止している人や、社外秘の資料しか材料がない人は、ChatGPTを個人のアカウントで使わないでください。

社内データ参照ならMicrosoft 365 Copilotを選ぶ

社内の情報を探して答えてもらう作業には、Microsoft 365 Copilot（Premium）を選びます。ファイルをアップロードしなくても、メール・ファイル・会議の内容を自動で参照するからです。

選ぶ理由：探しに行かなくても社内情報を参照する

「先週の会議で何が決まった？」「あの案件の最新の見積もりはどのファイル？」といった質問に向いています。公式ドキュメントによると、Premiumのライセンスでは、Microsoft Graph・Work IQ・Copilot Search・セマンティックインデックスを通じて、メール・ファイル・会議・予定表・チームといった社内データをもとに答えます。参照したいファイルを指定することもできますが、手作業でアップロードする必要はありません（What is Microsoft Copilot? | Microsoft Learn）。

Work IQはオン・オフを切り替えられます。オフにすると、社内データを使わずに答えます。

権限の扱いと、導入前に確認すること

Copilotが参照できる範囲はそのユーザーの権限の範囲内だけです（What is Microsoft Copilot? | Microsoft Learn）。言い換えると、もともと共有範囲が広すぎるファイルは、そのまま回答の材料になります。

Microsoftは、共有しすぎの見直しや使われていないサイトの整理を助けるSharePoint Advanced Management、機密度に応じてデータにラベルを付けるMicrosoft Purviewを案内しています（同上）。導入する前に、次の3つを情報システム担当と確認しましょう。

  1. 「全員に共有」になっているSharePointサイトやファイルがないか
  2. 人事・給与など機密性の高い情報の置き場所と、アクセス権限
  3. 最初に試す部署と、使い方の社内ルール

無料のCopilot Chatではできないこと

Copilot Chat（Basic）とMicrosoft 365 Copilot（Basic）では、Microsoft Graphを使った社内データの参照はできません。社内の情報を使うには、ファイルをアップロードするか、OutlookやTeamsで開いている内容を使うか、従量課金のエージェントを使う必要があります（What is Microsoft Copilot? | Microsoft Learn）。「Copilotは使えるのに社内のことを答えてくれない」というときは、ライセンスの違いが原因かもしれません。

Microsoft 365を使っていない会社の場合

社内の情報がGoogle DriveやSlackなどにある会社は、ChatGPTやClaudeの連携機能が候補になります。

  • ChatGPT：Business・Enterprise・Eduプランの「company knowledge」は、Slack、SharePoint、Google Drive、GitHubなどの情報をもとに、出典つきで答えます。もとの権限も守られると説明されています（Company knowledge in ChatGPT）。
  • Claude：Microsoft 365コネクタを使うと、SharePoint・OneDrive・Outlook・Teamsの内容を検索して分析できます。仕事用のMicrosoft Entraアカウントが必要で、個人のMicrosoftアカウントでは使えません（Connect to Microsoft 365）。

Microsoft 365を中心に仕事をしている会社なら、追加の接続設定なしで社内情報を参照できるMicrosoft 365 Copilotが、いちばん迷わない選び方です。

向いていない人：Microsoft 365を使っていない会社、個人事業主、共有設定を見直す時間がとれない会社。

長文コード生成ならClaude（Claude Code）を選ぶ

複数のファイルにまたがる機能追加や、大きなプログラムの修正には、Claude Codeを選びます。コードベース全体を読み、編集から実行・確認までを一続きで進められるからです。数十行のコードを書くだけなら、どのサービスでも十分です。

選ぶ理由：コードベース全体を相手にできる

公式ドキュメントでは、Claude Codeは「コードベースを読み、ファイルを編集し、コマンドを実行し、開発ツールと連携するエージェント型のコーディングツール」と説明されています。やりたいことを普通の言葉で伝えると、進め方を計画し、複数のファイルにまたがってコードを書き、動くかどうかを確かめます（Claude Code overview）。

公式では、「認証モジュールのテストを書いて実行し、失敗したら直して」と頼む例が紹介されています（同上）。

開発の流れにそのまま入れられる

Claude Codeには、長い作業に向いた仕組みがそろっています（Claude Code overview）。

料金と注意点

Claude Codeは、Pro（月額20ドル）以上の有料プランで使えます。たくさん使うなら、利用枠が大きいMax（月額100ドルから）もあります（Claude Pricing、2026年10月時点）。

ほかの選択肢もあります。ChatGPTにはコーディング用の「Codex」があり、プランごとの内容は公式のCodex料金ページで案内されています（Codex Pricing）。社内でGitHub Copilotがすでに標準になっているなら、それを使い続けるのも現実的です。

どのツールを使う場合でも、AIが書いたコードをそのまま本番環境に出さないでください。人がレビューとテストをする手順は必ず残しましょう。

向いていない人：ターミナルやGitをまったく使ったことがない人は、まず公式のクイックスタートで基本を押さえてから始めましょう。会社のコードを扱うなら、社内ルールで許可されているかの確認も必要です。

立場別：最初の1つをどう選ぶか

最初の1つは、「会社が許可しているか」を確かめてから、いちばん時間を取られている作業に合わせて選びます。

会社員・管理職の場合

まず、勤め先がどのツールを許可しているかを確認してください。会社のMicrosoft 365にCopilotが入っているなら、社内データの参照にはそれを使うのがいちばん安全で手軽です。管理職の人は、部下にAIを使わせる前に「入れてよい情報」と「入れてはいけない情報」を決めておきましょう。

社外向けの資料作成にChatGPTを使いたいときは、会社が法人プランを契約しているか、社内ルールで使ってよいかを先に確かめます。個人のアカウントに社外秘の情報を入れるのは避けてください。

個人事業主の場合

社内データと呼べるほどの情報がまだ多くないなら、Microsoft 365 Copilotは後回しで構いません。提案書や報告書を作ることが多いならChatGPT、Webサイトや業務ツールを自分で作るならClaudeから始めるのがわかりやすいでしょう。両方を最初から有料で契約する必要はありません。まず無料プランで、自分の仕事に合うかを確かめてください。

AIを学びたい・仕事にしたい人の場合

1つのツールの操作を覚えるより、「この作業にはどのツールが向いているか」を公式情報から判断できる力のほうが長く役に立ちます。自分の仕事を「資料作成」「社内の情報を探す」「コードを書く」の3つに分けて、この記事の表に当てはめてみてください。なお、AIのスキルを身につければ必ず収入が増える、というものではありません。

使い分けで失敗しないための注意点

失敗はたいてい、名前の似た製品の取り違えと、ライセンスの勘違いから起こります。

  • 名前の似た製品を区別する：「Copilot」には、Microsoft 365 Copilot、Copilot Chat、GitHub Copilotなどがあり、それぞれ別の製品です（What is Microsoft Copilot? | Microsoft Learn）。
  • ライセンスで機能が変わる：同じCopilotでも、社内データを自動で参照できるのはPremium（アドオン）だけです。
  • 無料で使える範囲を確かめる：Claude Codeは有料プランだけで使えます（Claude Pricing）。
  • 情報の扱いを決めておく：社内データにつなぐときは、管理者が連携先や権限を管理できるかを確認しましょう。ChatGPT Businessでは、管理者が特定の連携を無効にできます（Company knowledge in ChatGPT）。
  • AIの答えは必ず確認する：資料の数字、社内情報の要約、生成したコードは、どれも最後に人が確認してください。
  • 機能や料金はよく変わる：契約や社内への展開の前に、公式ページを見直しましょう。

よくある質問

3つとも契約しないといけませんか？

いいえ、その必要はありません。いちばん時間を取られている作業に合うツールを1つ選び、無料プランか会社が契約しているもので試すところから始めてください。ChatGPTとClaudeには無料プランがあります（ChatGPT Free Tier FAQ、Claude Pricing）。

会社のMicrosoft 365でCopilotが使えるのに、社内のファイルについて答えてくれません。なぜですか？

ライセンスが、Copilot ChatかMicrosoft 365 Copilot（Basic）の可能性があります。これらはMicrosoft Graphを使った社内データの自動参照に対応していません。社内データを自動で参照するには、Premium（アドオン）のライセンスが必要です（What is Microsoft Copilot? | Microsoft Learn）。

Claude Codeは無料で使えますか？

使えません。2026年10月時点では、Pro・Max・Team・Enterpriseの有料プランに含まれていて、無料プランでは使えません（Claude Pricing）。

資料作成にはClaudeやCopilotは使えないのですか？

使えます。Claudeの無料プランでもファイル作成やArtifactsを使えますし、WordやPowerPointのCopilotはBasicのライセンスでも標準アクセスで使えます（Claude Pricing、What is Microsoft Copilot? | Microsoft Learn）。この記事では、編集できるファイルを作る機能を公式ヘルプが詳しく説明している点を重視して、ChatGPTを1番目に挙げています。

Copilotに社内データを見せても、見てはいけない情報は出てきませんか？

参照できるのはユーザーの権限の範囲内だけです。ただし、共有範囲がもともと広すぎるファイルは答えに出てくることがあります。導入前に、SharePoint Advanced ManagementやMicrosoft Purviewで共有設定を見直しておきましょう（What is Microsoft Copilot? | Microsoft Learn）。
